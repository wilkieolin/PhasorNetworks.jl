Fractional Power Encoding API

Fractional power encoding (FPE) and residue codes: FPEEncoder writes real values into phases, v_bind adds encoded values without carries, and Resonator factors a bound address back into its codebook entries. See docs/fpe_resonator.md for measured capacity and the status of the spiking path.

PhasorNetworks.HEX_AXES — Constant
HEX_AXES

Three unit vectors at 120° (k₁ + k₂ + k₃ = 0), used by FPEEncoder(mode = :hex). Rows are the axes, columns the 2-D input coordinates.

PhasorNetworks.FPEEncoder — Type
FPEEncoder(in_dims => out_dims; mode = :residue, moduli = Int[],
           bandwidth = 1f0, exponent = :random, layout = :bound,
           random_offset = false) <: Lux.AbstractLuxLayer

Fractional-power encoder: real coordinates x ∈ ℝ^in_dims ↦ D = out_dims phases θ_j = Σ_a Ω[j, a] x_a + ψ_j (mod 2π). Output is a Phase array in the library's [-1, 1] (units of π) convention, so every downstream phase-domain layer (v_bind, Codebook, PhasorDense, MakeSpiking → spike times) accepts it directly.

Modes

  • :uniform — Ω[j, a] ~ U(−B, B) rad per unit input (bandwidth = B). Similarity kernel between two inputs is ∏_a sinc(B Δx_a / π): similar for nearby inputs, orthogonal beyond ≈ π / B (Frady et al. 2021).
  • :residue — K = length(moduli) root-of-unity bases. Component j of modulus block k gets Ω = 2π r_j / m_k with r_j = 1 (exponent = :unit, smooth periodic kernel cos(2π Δx / m_k)) or r_j drawn uniformly from {0, …, m_k − 1} (exponent = :random, Kymn et al. 2024: each residue is a quasi-orthogonal vector, delta kernel; components with r_j = 0 are constant for that modulus). The block stores exactly x mod m_k; with pairwise coprime moduli the code is unique over ∏ m_k integers.
  • :hex — :residue over the three 2-D axes k₁, k₂, k₃ at 120° (k₁ + k₂ + k₃ = 0, HEX_AXES); requires in_dims == 2. The three axis phases satisfy φ₁ + φ₂ + φ₃ ≡ 0.

Layout (how moduli and axes share the D components)

  • :bound — every component carries every (modulus, axis) factor: θ_j = Σ_{k,a} 2π r_{jka} x_a / m_k. The output is the bind of the per-factor encodings (∏_{k,a} z_{ka}(x_a)), one dense pseudo-random address vector. Decoding needs the Resonator (vector form, Kymn).
  • :blocks — the D components are partitioned into K × A blocks, one per (modulus, axis); each block is a separate FPE of one factor. Decodable block by block with a Codebook (channel / concatenation form, Fiete).

random_offset = true adds a fixed random phase ψ_j per component (assigned to factor (k = 1, a = 1) in fpe_codebook so that the bind of the codebook entries still reproduces the encoder output exactly).

Residue mapping (moduli ↔ ω ↔ block)

For moduli = [m_1, …, m_K] and :blocks layout, modulus m_k occupies components blocks[k]+1 : blocks[k+1] (near-equal partition of D), with ω = 2π r_j / m_k rad per unit input, i.e. 2 r_j / m_k in the library's units of π. Query the table with fpe_table.

Shapes

Input (in_dims, B) (or a vector of B scalars when in_dims == 1, or (in_dims, L, B) for a sequence); output (D, B) / (D, L, B) Phase.

Spiking path

Phase → spike time is the library's encoder convention: follow the layer with MakeSpiking(spk_args, repeats); the spike train carries θ_j as the spike time within each carrier cycle, and v_bind on two such trains is a spike delay (spike_phase_bind).

State (no trainable parameters)

  • weight::Matrix{Float32} (D, in_dims) — total frequency Ω in units of π
  • omega::Array{Float32, 3} (D, A, K) — per-(axis, modulus) frequency
  • axes::Matrix{Float32} (A, in_dims) — identity or HEX_AXES
  • offset::Vector{Float32} (D,) — ψ in units of π (zeros unless random_offset)
  • blocks::Vector{Int} — block boundaries for :blocks layout ([0, D] for :bound)

PhasorNetworks.Resonator — Type
Resonator(codebooks; iterations = 50, projection = :abs, tol = 1f-3, sequential = true)
Resonator(e::FPEEncoder, st; kwargs...)

Resonator network (Frady, Kent, Olshausen & Sommer 2020): factor a composite phasor vector s = ⊙_f c_f into one codeword c_f per codebook codebooks[f]::AbstractMatrix{<:Phase} of shape (D, m_f). Each factor estimate x̂_f is refined by unbinding the current estimates of all other factors from s, projecting onto its codebook by similarity, and returning to the torus:

  • projection = :abs (default) — x̂_f ← ∠ C_f |C_fᴴ ê_f|, where ê_f = s ⊘ ⊙_{g≠f} x̂_g: every codeword is bundled with weight equal to the magnitude of its complex similarity to the unbound estimate, then each component returns to the unit circle. The magnitude is invariant to the global phase the other factors' estimates carry during the search, which is why this cleanup reaches far larger products ∏ m_f than the linear projection below.
  • projection = :linear — x̂_f ← ∠ C_f (C_fᴴ ê_f): the complex codebook-subspace projection followed by the phasor non-linearity, the update of Frady et al. 2020 (eq. 7, phasor variant) and Kymn et al. 2024.
  • projection = :codeword — snap to the single best codeword each step (coordinate ascent on the reconstruction similarity; the baseline that gets stuck in spurious fixed points from a random start).

Updates are sequential (Gauss–Seidel, each factor sees the latest estimates of the others) or synchronous (sequential = false). The loop runs at most iterations sweeps and stops when every component of every estimate moves by less than tol (chordal distance) over a full sweep.

Forward

(r::Resonator)(s::AbstractArray{<:Phase}, ps, st) with s of shape (D,) or (D, B) returns

(indices = (F, B) Int matrix, converged = BitVector(B), iterations = Vector{Int}(B),
 similarity = Vector{Float32}(B))

and the updated state (its RNG advances: every factor starts from a random phasor vector, because the superposition of a root-of-unity codebook is zero). indices[f, b] is the codeword of factor f with the largest |⟨c, ê_f⟩| at the last sweep; similarity is the cosine similarity between s and the bind of the selected codewords (1 for an exact factorisation).

A SpikingCall input is read out per cycle: the last carrier cycle's spike times become phases (train_to_phase) and the phase path runs; see docs/fpe_resonator.md for what a cycle-by-cycle spiking loop still needs. Inference only (not differentiable).

State

  • codes::Vector{Matrix{ComplexF32}} — unit phasors of each codebook
  • rng — initial-guess RNG

PhasorNetworks.crt_decode — Method
crt_decode(residues, moduli) -> Int

Chinese-remainder reconstruction: the unique x ∈ [0, ∏ m_k) with x ≡ residues[k] (mod moduli[k]) for pairwise coprime moduli. Residues are 0-based (as the codebook column index minus one).

source
PhasorNetworks.fpe_codebook — Function
fpe_codebook(e::FPEEncoder, st, k = 1, a = 1; levels = 0:m_k-1) -> Matrix{Phase}

(D, length(levels)) codebook of factor (modulus k, axis a): column i is the encoder's contribution for input level levels[i] on that factor alone (zero on all other factors). Factor (1, 1) carries the random offset ψ, so for integer inputs v_bind over all factors' selected columns reproduces the encoder output exactly. For :uniform mode pass continuous levels.

source
PhasorNetworks.fpe_codebooks — Method
fpe_codebooks(e::FPEEncoder, st) -> Vector{Matrix{Phase}}

All K × A factor codebooks, ordered modulus-fastest (f = k + K*(a-1)), as the Resonator expects. Residue modes only.

PhasorNetworks.fpe_table — Method
fpe_table(e::FPEEncoder, st) -> Vector{NamedTuple}

The residue mapping table: one row per factor with modulus, axis, omega_rad (2π/m, the base frequency in rad per unit input), block (component range for :blocks layout; 1:D for :bound) and exponent.
