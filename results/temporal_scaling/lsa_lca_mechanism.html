PhasorLSA / PhasorLCA — how the mechanisms actually work

Both are pointwise in the sequence axis L: the attention step runs independently at each position (l,b). The only cross-timestep transport is the λ-conv SSM memory inside the PhasorDense projections. Shapes use D=d_model, H=n_heads, Dh=D/H, L positions, B batch, A=n_anchors. Diagram uses H=4.

Each of q/k/v_proj is a full dense D→D map (every output channel sees all input channels). The head split is a reshape of the output into H contiguous Dh-slices — same as vanilla MHA. What differs is the next step.

Contrast with vanilla MHA: there, head h attends across the L sequence positions (an L×L matrix) and heads are independent (recombined only by W_O). Here the attended set is the H heads themselves (an H×H matrix), per position, and there is no W_O and no cross-position mixing. Routing resolution = H (e.g. 4).

No q_proj: the query is a fixed learned anchor bank (content-addressable memory). k/v_proj are full dense D→D, then split into heads. Every head has its own slice of the anchor bank.

Heads are fully independent — each does its own anchor retrieval + bind on its own Dh-slice; there is no head-to-head mixing (unlike LSA) and no cross-position mixing. Set V_h to zero phase and this reduces to pure Hopfield retrieval.
