Base architecture

An LRU/S5-style SSM-MLP — not a Transformer. Each block = a residual attention sublayer (pointwise across heads/anchors, no cross-position routing) then a residual FFN whose PhasorDense layers carry the causal λ-conv SSM memory — the only cross-timestep transport. Both sublayers are ReZero-gated (α₀=0.1) with phase-addition skips.

Bottom line for the audio scale-up

Configuration these results point to: shallow (2–3 blocks), moderately wide (D≈96), FFN with ffn_n_modes=2, and tau_max matched to the evidence/utterance timescale. Width + a small SSM state-expansion bank are the high-leverage levers; depth is not. Natural next experiment: knob 2 — Mamba-style input-dependent selection over the mode-bank.
